List of Files:

* U_CCI_List.xml
  - CCI List in XML format

* cci2html.xsl
  - Stylesheet for viewing CCI List as HTML

* U_CCI_List.html
  - CCI List in HTML format

Note: In an effort to comply with the same-origin policy security model, Firefox and Chrome-based browsers (e.g., Chrome and Edge) have been modified so they do not load local .XSL files. This means you will not be able to view stylized XML CCI List content in a browser. Internet Explorer is reported to work, but that functionality could change. Firefox and Chrome users should use the HTML version of the CCI List.
